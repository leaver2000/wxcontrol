Live data with wxserver

Run docker compose up in the repository. The ingest service pulls HRRR and RRFS GRIB2 from NOAA (byte ranges selected via the .idx inventories), computes CAPE, CIN, LCL and lifted index with nzthermo, and commits each forecast hour to an Icechunk repository in MinIO. The server service serves /api/catalog, /api/map and /api/point; this page finds them on its own origin and switches to live data, with a model and run picker in the header.
